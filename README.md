SEO Best Practices:

Throughout the creation of the website, SEO best practices have been taken into account to enhance visibility and access to the site by search engines. This involved the use of proper HTML code with semantics, appropriate page titles, meta descriptions, and heading hierarchy. The website has been organized in a manner that enhances readability and ease of navigation. In addition, there is image optimization and responsive design on the website, which are some of the factors that enhance user experience. Best SEO Practices

The SEO best practices were employed in an attempt to assist search engines in discovery, crawling, and understanding the website's content. These include the use of robots.txt file and sitemap.xml file for assisting in crawling and indexing of the website.

Robots.txt file is a file where instructions are provided to search engine crawlers about what parts of the website they can access or cannot access. This is done in order to direct the crawlers to the relevant website contents, although it does not mean that those pages will not be crawled in search engine result pages.
Sitemap.xml is a file that provides a list of all important URLs in the website. In this way, search engines will be able to discover which pages exist on the website and need to be crawled and indexed.
In addition to descriptive page titles, relevant meta description, semantic HTML, and header structures, these techniques create a base of SEO. Although, their implementation does not guarantee any ranking or indexing, they make it easier for search engines to navigate through the website.
