Part 1 Details – HTML Development

Part 1 of the Stitch and Seam Tailoring website project focuses on developing the foundational structure and content of the website using HyperText Markup Language (HTML5). The purpose of this stage is to establish the layout of the website, organise its content and ensure that users can navigate between the different pages easily. HTML provides the basic structure upon which the visual styling and interactive functionality will be developed in Parts 2 and 3.
The website consists of five main pages: Home, About, Services, Enquiry and Contact. Each page has been created as a separate HTML document to ensure that information is organised into clearly defined sections and that visitors can access the information they are looking for without unnecessary difficulty.

Home Page (index.html)
The Home page serves as the main introduction to Stitch and Seam Tailoring. It welcomes visitors to the website and provides an overview of the business and its tailoring services. The page includes a navigation menu that allows users to access the other sections of the website. It also contains introductory content and links directing visitors towards the Services and Enquiry pages.

About Page (about.html)
The About page provides background information about Stitch and Seam Tailoring. It introduces the business, explains its purpose and communicates the values that guide its services. This page is intended to help visitors understand the business and establish a sense of trust and familiarity with potential customers.

Services Page (services.html)
The Services page outlines the different tailoring services that customers can enquire about. These include clothing alterations, garment repairs, custom tailoring and adjustments to formal and everyday clothing. Each service is presented in its own section with a short description to help visitors understand what the business offers.

Enquiry Page (enquiry.html)
The Enquiry page provides a form through which potential customers can submit information about the tailoring services they require. The form includes fields for the customer's name, email address, phone number, service required and a message describing their request. HTML form elements and input types are used to organise the information and identify required fields. Additional form validation and interactive responses will be implemented during Part 3 using JavaScript.

Contact Page (contact.html):
The Contact page provides a dedicated section for visitors who wish to contact Stitch and Seam Tailoring. It is designed to display the business's contact information, including its telephone number, email address and physical location. This page also directs visitors to the Enquiry page if they would like to submit a more detailed service request.

HTML Structure and Implementation:
Throughout Part 1, HTML5 elements have been used to organise the website content into meaningful sections. Elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` and `<footer>` help establish a consistent structure across the five pages. Headings, paragraphs, links, lists and form elements are used to present information in a clear and organised manner.
Each HTML document includes the appropriate document declaration, language attribute, character encoding and viewport settings. These elements help ensure that the website is interpreted correctly by web browsers and can be displayed on different screen sizes.
A consistent navigation structure has also been included across the pages, allowing visitors to move between Home, About, Services, Enquiry and Contact. Descriptive page titles and meta descriptions have been added to improve page identification and provide basic search engine information.

Part 1 Outcome:
The completion of Part 1 establishes the foundation of the Stitch and Seam Tailoring website. All five pages have been structured and populated with relevant introductory content, navigation links and the necessary HTML elements. The initial website structure provides a foundation for the next stages of development.
Part 2 will focus on applying Cascading Style Sheets (CSS) to improve the website's appearance through colours, typography, spacing, layouts and responsive design. Part 3 will introduce JavaScript to provide additional functionality, including interactive navigation, search functionality and enquiry form validation.
Overall, Part 1 demonstrates the use of HTML5 to develop a structured, organised and user-friendly multi-page website.

Part 2:

Introduction
Part 2 of the Stitch and Seam Tailoring website focused on the visual design and styling of the website using CSS (Cascading Style Sheets). The purpose of the CSS was to create a professional, modern and visually appealing website that reflects the identity of a tailoring business.

Colour Scheme
The website uses a simple and professional colour scheme consisting mainly of:
- Black: Used to create a bold, elegant and professional appearance.
- Grey: Used for secondary backgrounds, borders and supporting elements.
- White: Used to improve readability and create contrast against darker backgrounds.

The combination of these colours gives the website a clean, minimalistic appearance while keeping the design consistent across all five pages.

Layout and Styling
CSS was used to control the overall layout and appearance of the website. This included:
- Styling headings, paragraphs and navigation links.
- Adjusting margins, padding and spacing to keep content organised.
- Applying consistent fonts, colours and backgrounds.
- Styling buttons, forms and other interactive elements.
- Creating a consistent navigation bar across all website pages.
- Using borders, shadows and other visual details to improve the presentation.

Hover Effects

Hover effects were added to selected website elements to make the website feel more interactive. When users move their mouse over navigation links, buttons or other selected elements, their appearance changes.
These effects help users identify clickable elements and improve the overall browsing experience.

Fade-in Animations
Fade-in effects were used to make selected content appear more smoothly when a page loads or when elements are displayed. This adds a subtle visual effect without making the website distracting or difficult to navigate.

Responsive Design
CSS was also used to help the website adapt to different screen sizes, including desktop and mobile devices. Media queries were used where necessary to adjust layouts and navigation for smaller screens.

Overall Outcome
The CSS styling helped transform the basic HTML structure into a complete and visually consistent website. The black, grey and white colour scheme, combined with hover effects and fade-in animations, gives Stitch and Seam Tailoring a clean, modern and professional appearance.

Conclusion:Part 2 successfully established the visual identity of the website and improved its usability, presentation and consistency across all five pages.

Part 3 Details – JavaScript Functionality and Website Optimisation

Introduction
Part 3 of the Stitch and Seam Tailoring website focused on adding functionality, improving the user experience and applying basic website optimisation techniques. JavaScript was used to make the website more interactive, while additional website features were considered to improve accessibility, search engine visibility, performance and security.

1. JavaScript Functionality
JavaScript was used to add interactive features to the website. These features help users navigate and interact with the different pages more easily.

Examples include:
- Interactive navigation menu for smaller screens.
- Button interactions and user feedback.
- Search functionality to help users find relevant website content.
- Form interactions to improve the enquiry process.
 2. On-Page SEO
On-page SEO refers to improvements made directly to the website to help search engines understand its content.

The following techniques were considered:
- Clear and descriptive page titles.
- Relevant headings and subheadings.
- Meaningful page descriptions.
- Relevant keywords relating to tailoring services.
- Descriptive text for images using alternative text (alt attributes).
- Clear and organised content across all five pages.

 3. Off-Page SEO
Off-page SEO refers to activities outside the website that can help improve its visibility and credibility online.

For a tailoring business, possible off-page SEO activities include:
- Sharing the website through social media platforms.
- Creating business profiles on relevant online directories.
- Encouraging genuine customer reviews.
- Building links from relevant local business websites.

These activities can help improve the website's online presence and attract potential customers.

 4. Sitemap
A sitemap provides a structured overview of the website's pages and how they are organised.

The Stitch and Seam Tailoring website contains five main pages:

- Home – `index.html`
- About – `about.html`
- Services – `services.html`
- Enquiry – `enquiry.html`
- Contact – `contact.html`

The sitemap helps visitors and search engines understand the website's structure and locate its different pages.

 5. Robots.txt File
The `robots.txt` file is used to provide instructions to search engine crawlers about which areas of a website they may or may not access.
It can help manage how search engines crawl the website. It is important to note that robots.txt is not a security feature and should not be used to protect private information.

6. Page Speed and Performance
Website performance is important because visitors expect pages to load quickly and smoothly.

The following techniques can help improve page speed:
- Keeping HTML, CSS and JavaScript files organised.
- Avoiding unnecessary code.
- Optimising image file sizes.
- Reducing unnecessary animations and effects.
- Using efficient CSS and JavaScript.

These techniques help create a smoother browsing experience, particularly for users accessing the website on mobile devices or slower internet connections.

7. Website Security
Basic security considerations were included in the website development process.

These include:
- Using client-side form validation to check information entered by users.
- Avoiding the collection of unnecessary personal information.
- Keeping website files organised and avoiding exposure of sensitive information.
- Using HTTPS when the website is hosted on a secure server.

Client-side validation improves the user experience, but it is not a replacement for server-side validation or other security measures.

 8. AJAX Form Submission
AJAX (Asynchronous JavaScript and XML) allows a website to send and receive information from a server without requiring the entire page to reload.

For the enquiry form, AJAX can be used to submit customer information asynchronously and display a response to the user.

Important: An actual AJAX form submission requires a server-side endpoint to receive and process the submitted information. If the current website only displays a JavaScript confirmation message, it should be described as a form interaction or simulated submission rather than a working AJAX submission.

 9. Client-Side Form Validation
Client-side validation was used to help ensure that users provide the required information before submitting the enquiry form.

Examples include:
- Checking that required fields are completed.
- Checking that an email address is entered in the correct format.
- Preventing the form from being submitted when required information is missing.
- Providing feedback when information is invalid.

This helps reduce incomplete submissions and makes the enquiry process easier for users.

Overall Outcome
Part 3 focused on improving the functionality, usability, visibility and performance of the Stitch and Seam Tailoring website. JavaScript provided interactive features, while SEO considerations, sitemap planning, robots.txt, page speed and security helped address important aspects of website development.

Conclusion: Part 3 brought together the functional and optimisation aspects of the website, helping create a more complete and user-friendly website for Stitch and Seam Tailoring.
